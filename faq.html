Frequently Asked Questions

What is AllToolsHub?

AllToolsHub is a mobile-friendly workspace bringing practical browser tools and AI-assisted workflows together.

Are all listed tools available?

No. The directory includes both working starter tools and planned tools. Each tool is labelled in the directory so visitors can tell whether it is currently available or still planned.

Does AI Chat work right now?

AI Chat needs a securely configured AI provider on the server. Until that is configured, the chat is in demo mode and does not send your message to an AI service.

Are the tools free?

The currently implemented browser-based tools can be used without a paid AI subscription. Some features may load third-party libraries and require an internet connection. Future AI features may have provider limits or costs.

Are my files uploaded?

Image and text tools are designed to process data in your browser where possible. PDF merging also runs in the browser after its library loads. Check the privacy policy and avoid entering sensitive information.

Can I use AllToolsHub on a phone?

The site is designed to adapt to mobile and desktop screens. Some operations may work better on a modern browser.

How can I report a problem?

You can review the public project repository and its issue tracker: AllToolsHub project issues.
